# 🚀 Map, Filter e Reduce — JavaScript

Projeto desenvolvido durante meus estudos de JavaScript com o objetivo de praticar e compreender na prática os principais métodos de manipulação de arrays: `map()`, `filter()` e `reduce()`.

A proposta do projeto é transformar conceitos fundamentais de JavaScript em exemplos práticos, facilitando a compreensão de como esses métodos podem ser utilizados no desenvolvimento de aplicações.

## 🧠 O que aprendi

### `map()`

O método `map()` permite criar um novo array a partir dos elementos de um array existente, aplicando uma determinada transformação em cada elemento.

Exemplo:

```javascript
const numbers = [1, 2, 3, 4, 5];

const doubled = numbers.map(number => number * 2);

console.log(doubled);
